# Web client

The branch includes a compact single-file runnable prototype at `index.html` for source browsing and review. The downloadable v0.2 archive is the fuller implementation with separated CSS/JS, the 100-quote data file, service worker, PWA manifest, generated opening wallpaper, due-time reminders, export, and expanded tests.

The source snapshot in this branch provides local task persistence, task completion/deletion, filters, quote rotation, a focus timer, and a reminder-permission request. It intentionally does not claim remote sync or native notification guarantees.
