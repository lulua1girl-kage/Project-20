# P-Exceptional Product and Feature Specification

## Core release
- Onboarding with local/account mode and data-use explanation
- Today dashboard: next action, priorities, plan, progress
- Inbox/quick capture
- Tasks: title, notes, priority, due date/time, estimate, tags, project, subtasks, recurrence
- Projects, sections, archive/restore
- Calendar/agenda
- Focus timer with pause/stop and session note
- Daily/weekly planning and review
- Local persistence and offline create/read/update/delete
- Sync queue, retry, conflict handling, status
- Reminder scheduling with permission explanation and quiet hours
- Search, filters, sorting, saved views
- Data export/import and account deletion flow
- Theme, text scaling, reduced motion, accessibility settings
- Empty/loading/offline/error states and diagnostics

## Motivation and certificates
- Optional habits, milestones, challenges, and progress history
- Missed-day recovery; streaks are optional and never punitive
- Authorized owner/admin can draft, preview, schedule, publish, edit, and retire challenges
- 100 original quotes rotate without immediate repetition; offline fallback
- Certificate rules are explicit and auditable; export/share as image/PDF
- Certificate includes unique verification ID and issuer; private task titles are excluded

## Advanced features after core reliability
- Explainable workload-aware planning suggestions
- Rule-based task breakdown; no paid AI dependency
- Templates, routines, goal hierarchy, milestones
- Platform widgets/shortcuts
- Optional calendar integrations with explicit scoped permission
- Optional challenge groups with moderation/reporting
- Importers and open-format export

## UX
- Today, Inbox, Projects, Calendar, Focus, Progress, Challenges, Settings
- Splash image is local, skippable, reduced-motion aware, and limited to about 2–3 seconds
- Dashboard and cached data load without internet; sync runs in background
- Dark palette: #09090B background, #151519 surfaces, #8F1727 dark red, #B3263A crimson, #F3E9EA primary text
- Avoid neon, excessive glow, manipulative streak loss, and decorative clutter

## Explicit non-goals for v1
- Required paid AI/API service
- Third-party advertising/tracking
- Public leaderboard by default
- Ranking user worth or performance from app activity
- Claiming all OS notifications are guaranteed
