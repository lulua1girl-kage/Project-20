# P-Exceptional — Project 20 App Specification v0.1

**Status:** Research/spec phase. No application source code is included yet.

P-Exceptional is a dark-red, offline-first productivity platform designed around dependable execution, intelligent planning, personal mastery, reliable infrastructure, and privacy/control.

## Product identity
- Working name: P-Exceptional (trademark/domain clearance pending)
- Theme: near-black, charcoal, restrained crimson, warm neutral text
- Launch: locally bundled hooded-girl gym artwork for 2–3 seconds, then app shell; never wait for internet to show the dashboard
- Core platforms: Android, iOS, Windows, macOS, Linux; web/PWA is a separately validated target
- Project repository: https://github.com/lulua1girl-kage/Project-20

## Five major targets
1. Execution: tasks, projects, priorities, deadlines, recurring work, subtasks, dependencies.
2. Intelligent planning: daily plan, time estimates, workload limits, focus blocks, review.
3. Personal mastery: optional challenges, milestones, habits, quote rotation, certificates.
4. Dependability: offline-first persistence, sync, notifications, backups, export/import.
5. Trust: transparent privacy, shared Project 20 identity, backend authorization, restrained admin analytics.

## Principles
- Human Override: users can pause, revise, skip, and recover.
- Engaging, not compulsive: no shame mechanics, artificial urgency, or raw time-on-app optimization.
- Local data is immediately usable; sync is asynchronous.
- No paid API or service required for core functionality.
- Admin analytics are aggregate by default; sensitive per-user activity is disclosed, restricted, audited, and retained briefly.

## Specification package
