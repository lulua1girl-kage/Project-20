# Development Standards

1. Every app has a distinct purpose and application ID.
2. Every app has a README describing purpose, features, setup, and limitations.
3. Do not claim a build, test, or device check passed unless it was executed.
4. Prefer offline functionality unless networking is essential to the app.
5. Request only permissions that are necessary and explain their purpose.
6. Keep UI state predictable and data handling explicit.
7. Avoid collecting personal data unless the app's function requires it.
8. Keep dependencies limited and document important choices.
9. Add tests for business logic and important state transitions.
10. Preserve working apps when adding new modules.
